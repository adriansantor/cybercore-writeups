# CyberCore - Documentación Colaborativa

Bienvenido a la documentación colaborativa de **CyberCore**, la asociación de ciberseguridad e informática forense.

## ¿Qué es este repositorio?

Este repositorio contiene las **notas de referencia rápida** utilizadas en las reuniones y sesiones de formación de CyberCore. Se trata de un compendio de conceptos, técnicas y herramientas esenciales en el campo de la ciberseguridad, organizadas de forma accesible para aprendizaje y consulta rápida.

Estas notas sirven como:
- 📚 **Material de referencia** para miembros de la asociación
- 🎯 **Guía de aprendizaje** en temas de seguridad ofensiva y defensiva
- 🔧 **Documentación de herramientas** y técnicas prácticas
- 💡 **Base de conocimiento compartido** de la comunidad

## Estructura del Contenido

La documentación se organiza en tres pilares principales:

### 🎓 Fundamentos
Conceptos básicos necesarios para cualquier profesional de TI:
- Linux y línea de comandos
- Networking y topologías
- Scripting en BASH

### ⚔️ Seguridad Ofensiva
Técnicas de evaluación de seguridad y pentesting:
- Enumeración y reconocimiento (Nmap)
- Técnicas de explotación (SQLi, transferencias de archivos)
- Información de seguridad e inteligencia

### 🛡️ Seguridad Defensiva
Prácticas para proteger sistemas y datos:
- Hardening de sistemas
- Seguridad en Linux (daemons, sockets, permisos)
- Principios de defensa y gestión de riesgos

## ¿Cómo usar esta documentación?

1. **Para principiantes**: Comienza con la sección [Conceptos & Útiles](Intro.md) para familiarizarte con los términos y comandos básicos.

2. **Para consulta rápida**: Usa el índice en [SUMMARY.md](SUMMARY.md) para encontrar rápidamente el tema que necesitas.

3. **Para aprendizaje profundo**: Sigue los diferentes módulos según tus intereses (ofensiva, defensa, scripting).

4. **Durante reuniones**: Estas notas se utilizan como material de referencia durante las sesiones de formación de CyberCore.
